# Foglio di ripasso personale

Scrivere qui un foglio breve, consultabile durante lo studio ma non durante la simulazione a tempo.

## Deve contenere

- Sequenza essenziale per un server TCP e per un client TCP.
- Sequenza essenziale per un server UDP e per un client UDP.
- Differenza pratica tra `send`/`recv` e `sendto`/`recvfrom`.
- Creazione di thread, passaggio degli argomenti e mutex.
- Struttura base di un messaggio e gestione delle stringhe ricevute.
- Apertura, scrittura e chiusura di un file di log.
- Comandi di compilazione, incluso `-pthread` quando necessario.
- Checklist finale: porte, IP, ordine di avvio dei processi, test e chiusura delle socket.
